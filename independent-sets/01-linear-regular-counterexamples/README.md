# Counterexamples for independent sets in linear regular hypergraphs

**Jialin He** · Manuscript 1 · 11 pages

We construct counterexamples to conjectured strong-independent-set bounds in linear regular uniform hypergraphs. A transversal-design lifting method also gives simultaneous strong and ordinary independent-set counterexamples in specified three-uniform degree ranges.
